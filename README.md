# אתר תדמית — מיכל לוי | Art, design and more...

אתר בעברית עם RTL מלא לאמנית ומעצבת הפנים מיכל לוי.
נבנה ב-React + Vite + Tailwind CSS, ללא בקאנד (אתר סטטי).

---

## הרצה מקומית

```bash
npm install
```

```bash
npm run dev
```

האתר יעלה ב-http://localhost:5173

בנייה לפרודקשן:

```bash
npm run build
```

התוצאה נכתבת ל-`dist/`. מעלים את **תוכן** התיקייה לשורש האחסון — אין צורך ב-Node
בשרת, אלה קבצים סטטיים בלבד.

## העמודים באתר

| עמוד | כתובת |
| --- | --- |
| עמוד הבית | `/` |
| הגלריה המלאה | `/#/gallery` |
| עמוד לכל מסלול | `/#/service/custom` · `interior` · `homevisit` · `workshops` · `consult` |

לחיצה על כרטיס ב"מה אני מציעה" נכנסת לעמוד של המסלול. לחיצה על "לגלריה המלאה"
נכנסת לגלריה.

**למה יש `#` בכתובת:** האתר סטטי. בלי ה-`#`, כשמישהו טוען `/service/custom`
ישירות או מרענן את הדף, השרת מחפש קובץ שלא קיים ומחזיר שגיאת 404 — אלא אם
מגדירים בשרת הפניה של כל נתיב ל-`index.html`, וזה משתנה מאחסון לאחסון. עם `#`
הכתובת עובדת בכל מקום, גם בהעלאה של תיקייה פשוטה.

אם האתר יעלה לשירות שתומך בזה (Netlify, Vercel, Cloudflare Pages) — מחליפים
ב-`src/App.jsx` את `HashRouter` ב-`BrowserRouter` וה-`#` נעלם.

## ⚠️ דבר אחד שחייבים לבדוק לפני העלייה לאוויר

### הטופס שולח לוואטסאפ — אין מה להגדיר

טופס יצירת הקשר לא עובר דרך שירות מייל חיצוני. לחיצה על "שליחה בוואטסאפ"
בונה הודעה מסודרת מהשדות שמולאו ופותחת שיחת וואטסאפ עם ההודעה כבר כתובה — בחירה
מכוונת: וואטסאפ כבר הערוץ הראשי של מיכל, וכך הטופס עובד מהרגע שהאתר עולה, בלי
חשבון, בלי מפתח API, ובלי סיכון שהודעה תיפול לספאם בלי שאף אחד ידע.

**מגבלה אחת שכדאי לדעת עליה:** קישורי `wa.me` יכולים למלא מראש רק טקסט, לא
לצרף קובץ. לכן אין שדה העלאת תמונה בטופס — יש הערה שמפנה לצרף את התמונה ישירות
בתוך השיחה שנפתחת. וגם: "נשלח" בפועל אומר שהשיחה נפתחה עם ההודעה מוכנה, לא
שההודעה נשלחה אוטומטית — הגולש עדיין לוחץ "שליחה" בתוך וואטסאפ עצמו.

## ★ הוספת תמונות וסרטונים — פשוט לגרור לתיקייה

**זה החלק החשוב.** אין רשימה לעדכן ואין קוד לגעת בו. שומרים קובץ בתיקייה
הנכונה, והוא מופיע באתר.

```
src/media/
  hero/                  ← התמונה הגדולה בפתיח (הקובץ הראשון שנמצא)
  gallery/               ← כל התמונות והסרטונים של הפרויקטים
  services/
    custom/              ← תמונות לעמוד "יצירת קיר בהתאמה אישית"
    interior/            ← תמונות לעמוד "עיצוב פנים מלא"
    homevisit/           ← תמונות לעמוד "ביקור בית אישי"
    workshops/           ← תמונות לעמוד "סדנאות יצירה"
    consult/             ← תמונות לעמוד "ייעוץ ותכנון"
```

ההסבר המלא — פורמטים, סדר התמונות, כתוביות, תמונת פתיחה לסרטון — נמצא ב-
**[`src/media/README.md`](src/media/README.md)**. בקצרה:

* **תמונות:** `.jpg` · `.png` · `.webp` · `.avif`  **סרטונים:** `.mp4` · `.webm`
* **`.mov` לא עובד בדפדפנים** — צריך להמיר (הפקודה נמצאת ב-README של התיקייה)
* מספר בתחילת שם הקובץ קובע את הסדר: `01-סלון.jpg`, `02-מבואה.jpg`
* כתובית מדויקת לפריט — שורה ב-[`src/data/mediaMeta.js`](src/data/mediaMeta.js) לפי שם הקובץ
* אחרי הוספת קבצים: `npm run build`

**מה קורה כל עוד התיקיות ריקות:** האתר לא נראה שבור. הגלריה מציגה תמונות דמה
(קבצי SVG שנוצרו בפלטת האתר), ועמוד הגלריה מוסיף הודעה שהתמונות האמיתיות בדרך.
עמוד של מסלול שאין לו תיקיית תמונות משלו מציג תמונות מהגלריה הכללית, כדי שלא
יהיה בו חור באמצע.

### הקרוסלה בעמוד הבית

סקשן "היצירות שלי" בעמוד הבית מציג את התמונות מ-`src/media/gallery/` כקרוסלה
שמתקדמת לבד — שקופית גדולה אחת בכל פעם, כדי שתמונות פורטרט (יצירות קיר) ותמונות
לרוחב (חללים) יוצגו כל אחת בשלמותה, בלי לחתוך אותן להתאמה לריבוע אחיד.

היא מתקדמת כל 4.5 שניות, נעצרת כששמים עליה עכבר או כשמעבירים אליה מיקוד
מהמקלדת, ומתחדשת כמה שניות אחרי שעוזבים. יש גם **כפתור עצירה גלוי** — זו לא
תוספת קוסמטית: כל תוכן שמתקדם לבד ונמשך מעל חמש שניות חייב אפשרות לעצור אותו
(WCAG 2.2.2), וקרוסלה בלופ היא בדיוק המקרה הזה. למי שהגדיר "תנועה מופחתת"
במערכת ההפעלה היא לא זזה כלל. לחיצה על שקופית פותחת אותה בתצוגה מוגדלת.

הגלריה המלאה (`/#/gallery`) נשארת רשת רגילה עם סינון — קרוסלה טובה להצגה, לא
לעיון בעשרות פריטים.

### דברים שעדיין חסרים

| מה | לאן לשמור | סטטוס |
| --- | --- | --- |
| תמונת הפתיח | `src/media/hero/` (קובץ אחד) | חסר |
| תמונות וסרטוני הפרויקטים | `src/media/gallery/` | ✅ 11 תמונות כבר בפנים |
| פורטרט של מיכל | `public/images/michal-portrait.jpg` | ✅ נשמר |

**לגבי הכתוביות של 11 התמונות שכבר הועלו** — הן ב-[`src/data/mediaMeta.js`](src/data/mediaMeta.js),
אבל אני ניחשתי אותן מתוך הסתכלות על התמונות בלבד. אין לי מושג איזה חדר זה,
מי הלקוח, או מאיזה חומר זה עשוי — כדאי לעבור עליהן ולתקן, זה עריכה של כמה
דקות בקובץ אחד, לא בנייה מחדש.

הפורטרט הוא היחיד שיושב במקום אחר ובשם קבוע. עד שהוא נשמר, סקשן "מי אני" מציג
תמונת דמה במקומו (הקוד מזהה שהקובץ חסר ומחליף — לא מוצגת תמונה שבורה).

## עדכון תוכן

כל הטקסטים יושבים ב-**`src/data/site.js`**: טלפון, אימייל, רשתות חברתיות,
טקסט הפתיח, פסקאות "מי אני", המסלולים (כולל הטקסט הארוך של כל עמוד), כתוביות
הגלריה ורצועת המספרים. אין צורך לגעת ב-JSX.

### הטקסט של עמוד מסלול

לכל מסלול ב-`services` יש:

| שדה | מה זה |
| --- | --- |
| `title` · `text` | הכרטיס בעמוד הבית |
| `tagline` | שורת המחץ בעמוד המסלול |
| `intro` | הפסקאות הארוכות |
| `steps` | "השלבים בדרך" — כל שלב עם כותרת וטקסט |
| `note` | הערה בתוך מסגרת (למשל שביקור בית הוא בתשלום) |

**הטקסט הארוך נכתב בכוונה בלי מחירים, בלי משכי זמן, בלי מספר משתתפים ובלי אזורי
שירות.** אלה נתונים שרק מיכל יכולה לקבוע, והמצאה שלהם היתה מציגה הבטחות שגויות
מול לקוחות. כשהיא מאשרת את המספרים — מוסיפים אותם ל-`note` או ל-`steps`.

### הוספת קישורי אינסטגרם ופייסבוק

ב-`src/data/site.js`, בתוך `contact.social`, להחליף את `'#'` בכתובות האמיתיות.
כל עוד הערך הוא `'#'`, האייקון בפוטר מוצג במצב מושבת ולא מוביל לשום מקום.

### הלוגו

הלוגו המקורי הגיע כתמונה, ולכן שורטט מחדש כ-SVG וקטורי ב-`src/components/Logo.jsx`
(האותיות L ו-M עם גג הבית מעליהן). היתרון: חד לחלוטין בכל גודל, ומקבל את צבע
הטקסט של ההקשר שבו הוא יושב.

אם מעדיפים את קובץ המקור — לשמור אותו כ-`public/images/logo.png` (רצוי PNG שקוף
או SVG), ולהחליף את ה-`<svg>` שבתוך `LogoMark` ב:

```jsx
<img src="/images/logo.png" alt="" className={className} />
```

## החלטות טכניות

**גילוי מדיה אוטומטי** — הקבצים ב-`src/media` נאספים ב-`import.meta.glob` בזמן
הבנייה. הסיבה שהם לא ב-`public/`: קבצים שם מועתקים כמו שהם ואי אפשר לרשום אותם
בקוד, כלומר היה צריך לעדכן רשימה ידנית על כל תמונה חדשה. מ-`src` הבנייה גם
מוסיפה חתימה לכל קובץ (כדי שדפדפנים לא יציגו גרסה מהמטמון) וגם נכשלת בקול רם אם
משהו שבור, במקום להחזיר 404 באתר החי.

**אנימציות גלילה** — `Reveal.jsx` עוטף כל סקשן ב-Intersection Observer קטן
(fade-in + slide-up עדין). בכוונה בלי Framer Motion: הרכיב הוא ~30 שורות,
לא מוסיף שום תלות לחבילה, והתנועה יוצאת מרוסנת. כל אלמנט נחשף פעם אחת.

**נגישות** — קישור "דילוג לתוכן הראשי", מיקוד מקלדת נראה בכל האתר, alt לכל
התמונות, ה-Lightbox הוא `role="dialog"` עם `aria-modal`, מלכודת מיקוד, סגירה
ב-Escape וניווט בחצים, והמיקוד חוזר לאריח שממנו נפתח. שגיאות הטופס עם
`aria-invalid` ו-`aria-live` ומיקוד אוטומטי לשדה השגוי. התפריט במובייל נועל
גלילה ונסגר ב-Escape, והקישורים בו לא נגישים למקלדת כשהוא סגור.
`prefers-reduced-motion` מבטל את כל התנועה. הפלטה כולה נבדקה ל-WCAG AA (ראו
ההערה ב-`tailwind.config.js`).

**RTL** — `dir="rtl"` על ה-html. במקומות שבהם יש טקסט לטיני או מספרים
(`Art, design and more...`, `30+`, `2 / 6`, טלפון, אימייל) יש `dir="ltr"` מקומי,
אחרת אלגוריתם ה-bidi מעיף סימני פיסוק לצד הלא נכון של השורה. גם ספירת הפריטים
בגלריה מנוסחת בעברית תקנית — "סרטון אחד" ולא "1 סרטונים".

**קישורי סקשנים** — מכיוון שהראוטר משתמש ב-`#`, הקישורים לסקשנים בעמוד הבית
גוללים בקוד ולא דרך `href="#about"`. זה גם מה שמאפשר להם לעבוד מתוך עמוד פנימי:
לחיצה על "מי אני" מתוך עמוד מסלול חוזרת לעמוד הבית ואז גוללת.

**רשת הכרטיסים** — הכרטיסים והשלבים ממוסגרים כל אחד בנפרד עם רווח ביניהם, ולא
ב-`gap-px` על רקע צבוע. הגרסה הראשונה עשתה את זה כך, ובעמודות ברוחב שאינו מספר
שלם חלק מרווחי ה-1px נעלמו בעיגול ומפרידים שלמים לא הופיעו.

**ביצועים** — תמונת הפתיח נטענת ב-`fetchpriority="high"` (היא ה-LCP), כל השאר
ב-`loading="lazy"`. סרטונים בגלריה נטענים ב-`preload="metadata"` ומתנגנים רק
כשפותחים אותם — רשת של סרטונים שמתנגנים לבד היא גם כבדה וגם רועשת ויזואלית.
ה-bundle הוא ~71KB gzipped.
