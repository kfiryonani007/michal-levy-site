# כאן שמים את התמונות והסרטונים

כל מה שנמצא בתיקיות שכאן נכנס לאתר **אוטומטית**. אין רשימה לעדכן ואין קוד לגעת בו —
שומרים קובץ, והוא מופיע.

```
src/media/
  hero/                  ← התמונה הגדולה בפתיח (הקובץ הראשון שנמצא)
  gallery/               ← כל התמונות והסרטונים של הפרויקטים
  services/
    custom/              ← תמונות לעמוד "יצירת קיר בהתאמה אישית"
    interior/            ← תמונות לעמוד "עיצוב פנים מלא"
    homevisit/           ← תמונות לעמוד "ביקור בית אישי"
    workshops/           ← תמונות לעמוד "סדנאות יצירה"
    consult/             ← תמונות לעמוד "ייעוץ ותכנון"
```

## פורמטים

**תמונות:** `.jpg` · `.jpeg` · `.png` · `.webp` · `.avif`

**סרטונים:** `.mp4` · `.webm`

⚠️ **`.mov` לא עובד בדפדפנים.** אם יש סרטון מהאייפון בפורמט MOV צריך להמיר אותו:

```bash
ffmpeg -i input.MOV -c:v libx264 -crf 24 -pix_fmt yuv420p -movflags +faststart -an output.mp4
```

## סדר התמונות

הקבצים מסודרים לפי שם, אז אפשר לשלוט בסדר עם מספר בהתחלה:

```
01-סלון.jpg
02-מבואה.jpg
03-סדנה.mp4
```

המספר לא מופיע בכתוביות באתר.

## תמונה נייחת לסרטון (poster)

אם רוצים שהסרטון יציג פריים מסוים לפני שהוא מתחיל — שומרים תמונה **באותו שם**:

```
03-סדנה.mp4
03-סדנה.jpg   ← תוצג כתמונת הפתיחה של הסרטון
```

התמונה הזו לא תופיע כפריט נפרד בגלריה.

## כתוביות

לא חובה. קובץ בלי הגדרות יופיע עם כתובית שנגזרת משמו. אם רוצים כתובית מדויקת —
מוסיפים שורה ב-[`src/data/mediaMeta.js`](../data/mediaMeta.js) לפי שם הקובץ.

## אחרי שמוסיפים קבצים

בזמן פיתוח (`npm run dev`) זה מתעדכן לבד. לפני העלייה לאוויר צריך לבנות מחדש:

```bash
npm run build
```
