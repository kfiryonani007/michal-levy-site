# קידוד סרטון ה-Hero

הסרטון הנוכחי: קליפ שנוצר ב-AI ("Woman painting colorful landscape"),
**1280×720 (לרוחב), 10 שניות, 24fps, עם קול**. הוא מסתיים בכיתוב קבוע ("הצטרפו
לקהילת האומנות שלי") ששרוף לתוך הפריימים עצמם — לא ניתן לערוך אותו, רק לחתוך
אותו החוצה.

## מה נעשה ולמה

1. **חיתוך ל-8.333 שניות (פריים 200 מתוך 240, ב-24fps)** — זה הפריים האחרון
   שעדיין נקי לגמרי מהכיתוב השרוף. בדקתי פריים-אחר-פריים (198–210) כדי למצוא
   בדיוק איפה הכיתוב מתחיל להופיע, כך שהלופ חוזר להתחלה בלי הבזק של הכיתוב
   הישן. אם מגיע סרטון חדש עם כיתוב דומה בסוף — הפקודה למטה מייצרת גריד
   פריימים לבדיקה ידנית.
2. **הסרת הסאונד (`-an`)** — דפדפנים חוסמים הפעלה אוטומטית של וידאו עם קול,
   והווידאו חייב להיות `muted` בכל מקרה.
3. **`-movflags +faststart`** — מעביר את טבלת האינדקס לתחילת הקובץ כדי שהניגון
   יתחיל מיד.
4. **WebM/VP9 בנוסף ל-MP4** — הדפדפן בוחר לבד: WebM ראשון (קטן יותר), MP4
   כגיבוי לספארי ולדפדפנים ישנים.
5. **לא נחתך לרוחב/גובה** — המקור כבר בפורמט לרוחב (16:9), אז אין צורך בחיתוך
   נפרד לדסקטופ ולמובייל כמו שהיה בסרטון האנכי הקודם. `object-cover` בדפדפן
   מטפל בהתאמה למסך.

**במקום הכיתוב השרוף** יש באתר תג "בואו לקנות את האומנות שלי" — טקסט אמיתי
ב-HTML/CSS בפלטת הצבעים של האתר (לבן על שקוף כהה, כמו כפתור העצירה), ולא
פיקסלים קבועים בתוך הווידאו. אפשר לערוך את הניסוח או להסיר אותו לגמרי דרך
`hero.buyBadge` ב-`src/data/site.js`, בלי לגעת בסרטון.

## הפקודות

```bash
ffmpeg -y -i "SOURCE.mp4" -t 8.333 -an -c:v libx264 -preset slow -crf 23 -pix_fmt yuv420p -movflags +faststart public/video/hero.mp4
```

```bash
ffmpeg -y -i "SOURCE.mp4" -t 8.333 -an -c:v libvpx-vp9 -crf 32 -b:v 0 -row-mt 1 -deadline good -cpu-used 2 public/video/hero.webm
```

```bash
ffmpeg -y -i "SOURCE.mp4" -frames:v 1 -q:v 3 public/images/hero-poster.jpg
```

בדיקת היכן כיתוב שרוף מתחיל להופיע (משנים את מספרי הפריימים לפי הצורך):

```bash
ffmpeg -y -i "SOURCE.mp4" -vf "select='eq(n\,198)+eq(n\,199)+eq(n\,200)+eq(n\,201)',scale=400:-1,tile=4x1" -frames:v 1 text-check.png
```
